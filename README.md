# pipisso FileDesk

Приложение для Windows для пакетной обработки файлов. Python + PySide6 / QML, Pillow, SQLite. Работает локально, без аккаунта и сервера.

## Версия 0.3

Бордовые панели с мягкими затемнениями, розовый градиентный фон, тонкая обводка и скругления по референсу. Окно без второй системной шапки: кнопки закрытия, сворачивания и разворачивания слева; перемещение за шапку и изменение размера за края.

1. Нажмите **Добавить файлы** или **Папку**, либо перетащите файлы в окно.
2. Выберите **Добавить номера**, **Задать общее имя** или **Заменить часть имени**.
3. Проверьте исходные и новые имена в таблице. Расширения сохраняются.
4. Нажмите **Переименовать**. В **Истории** появятся результаты; кнопка **Отменить** восстанавливает имена после проверки файлов и конфликтов.

Выбор файлов выполняется системным диалогом через Python. Для перетаскивания URL явно преобразуются в строки. Недоступные пути показываются в сообщении, ошибки обработки — в строках файлов. По умолчанию включена нумерация, которая действительно меняет имена. Режим «Демо» поддерживает предпросмотр, запуск, историю и отмену без изменения файлов на диске.

**Обработка изображений, сортировка, поиск дубликатов и сценарии пока не реализованы.** Сейчас доступно пакетное переименование. Полупрозрачность и мягкие цветовые переходы рисуются внутри приложения; это не системное размытие рабочего стола.

## Запуск из исходников

Python 3.11 или новее:

```sh
python -m venv .venv
# Windows:
.venv\Scripts\activate
python -m pip install -e ".[dev]"
python run.py
```

## Сборка Windows

Настроен workflow GitHub Actions: Linux/Windows-тесты → сборка PyInstaller → проверка запуска собранного exe → ZIP-артефакт `FileDesk-Windows-preview`. Результаты сборки и тестов доступны во вкладке Actions. Перед скачиванием проверьте успешное завершение всех шагов.

После успешного запуска: GitHub Actions → Checks and Windows preview → Artifacts → FileDesk-Windows-preview. Распакуйте весь архив и запустите FileDesk.exe. Папка `_internal` должна оставаться рядом с exe. Python для переносной сборки не нужен. Сборка не подписана цифровой подписью.

Сборка вручную на Windows:

```sh
python -m PyInstaller --noconfirm --windowed --name FileDesk --collect-data filedesk run.py
```

Установщик и GitHub Release запланированы на этапе 8 после проверки функций и запуска на Windows без Python.

## Ограничения и сохранность файлов

- Программа не перезаписывает существующие файлы. Обмен имён и изменения только регистра пока запрещены.
- Ссылки и junction-папки пропускаются. Переименование выполняется только в той же папке.
- Пакет не является одной транзакцией: при остановке уже выполненные изменения сохраняются в журнале и доступны для отмены.
- При аварии между файловой операцией и записью результата в SQLite соответствующая запись помечается для ручной проверки. Автоматического угадывания состояния нет.
- Не изменяйте обрабатываемые файлы параллельно в других программах. Проверки снижают риск конфликтов, но не обеспечивают блокировку от конкурентного изменения сторонними процессами.
- Linux-реализация использует hard link + unlink без перезаписи; файловая система должна поддерживать жёсткие ссылки. Windows использует `os.rename`, который отказывает при существующем назначении.
- История и настройки находятся в системной папке данных FileDesk. Журнал содержит локальные пути; в репозиторий он не включается. При удалении журнала возможность отмены теряется.
- Системное размытие пока не реализовано. Окно использует собственное оформление и системные операции перемещения/изменения размера.

## Проверки

```sh
python -m pytest -q
python run.py --smoke
```

Локально под Linux/offscreen: **35 тестов прошли**. Проверены сохранение настроек, загрузка QML, темы и разделы, добавление → предпросмотр → реальное переименование → отмена через фоновый обработчик; кириллица, длинные пути, пустые файлы, конфликты, изменение файлов, остановка и восстановление журнала. Отказ доступа моделируется тестом; реальные блокировки Windows и DPI ещё требуют проверки под Windows.

См. [план](docs/PLAN.md), [архитектуру](docs/ARCHITECTURE.md), [проверку Windows](docs/VISUAL_CHECK.md).

В сборке выполняется `FileDesk.exe --self-test`: проверяется путь от QML-кнопок и импорта URL до изменения настоящих временных файлов, истории, отмены и деморежима. Нативный диалог в автотесте заменён заранее выбранными временными путями; ручной выбор в Проводнике и поведение окна на конкретном ПК требуют визуальной проверки. Отчёт и снимок окна доступны в артефакте `FileDesk-selftest-report`.
