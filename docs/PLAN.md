# План FileDesk

Порядок: основа → внешний вид → переименование → изображения → сортировка и дубликаты → сценарии → выпуск. После каждого этапа проверять результат и фиксировать его в git.

1. **Оформление и структура.** pipisso / FileDesk, меню «Файлы / Сценарии / История / Настройки», очередь по центру, параметры справа, запуск и прогресс снизу. Графит и приглушённый бордовый фон, светлая тема, читаемые параметры. Зафиксировано в первой версии.
2. **Основа.** Python, PySide6, QML, Pillow, SQLite; запуск, настройки, CI. Реализовано, результаты проверок см. в GitHub Actions.
3. **Интерфейс для оценки.** Сворачиваемое меню, таблица, темы, состояния, подсказки, короткие анимации, пустая очередь, демонстрация прогресса и ошибки. Реализована предварительная версия; требуется оценка Windows-сборки пользователем.
4. **Добавление и переименование — реализовано локально, 35 тестов прошли; Windows-проверка ожидается.** Файлы/папки/drag-and-drop, шаблон, нумерация, поиск и замена, было/станет, проверка Windows-имён и коллизий, журнал и безопасная отмена. Проверить кириллицу, длинные пути, одинаковые имена, занятые файлы, права доступа.
5. **Изображения.** JPEG/PNG/WebP, размер, пропорции, качество, EXIF-ориентация, фон прозрачности для JPEG. Фоновая очередь с прогрессом и остановкой, отдельный вывод, продолжение после ошибки. Проверить повреждения, прозрачность, большие файлы и отмену.
6. **Сортировка и дубликаты.** По расширению, типу, дате изменения; предпросмотр путей. Точные копии по содержимому, выбранные копии перемещаются в папку проверки. Проверить пустые файлы, коллизии, совпадения с разными именами.
7. **Сценарии и история.** Настраиваемые цепочки, сохранение/редактирование/повторный запуск. Завершённые, пропущенные, ошибочные файлы. Незавершённые операции после перезапуска помечать прерванными.
8. **Выпуск.** Переносная сборка и установщик, чистая Windows без Python, DPI и большие очереди, README, скриншоты, демонстрационные файлы, архитектура, проверенная сборка в Releases.

Первая контрольная точка: оценка интерфейса этапа 3 до реализации всех функций. Реализовано переименование этапа 4. Функции этапов 5–8 пока не реализованы. Публикация исходников разрешена пользователем. Результаты Windows CI проверять во вкладке Actions.

Обновление 0.3: интерфейс переработан по изображению, добавлен полноценный деможурнал, выбор файлов перенесён в нативные Python-диалоги, готовый exe проверяет полный сценарий переименования.
