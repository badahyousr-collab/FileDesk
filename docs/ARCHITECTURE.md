# Архитектура

- `filedesk/qml/Main.qml`: Qt Quick интерфейс, палитры,  drag-and-drop, таблица предпросмотра и история.
- `filedesk/app.py`: QApplication, нативные QFileDialog, раздельные реальные и демонстрационные данные, QObject-мост, очередь фоновых задач на QThread; сигналы передают результаты в главный поток. Дебаунс предпросмотра 350 мс. Во время работы параметры заблокированы; закрытие окна сначала запрашивает остановку.
- `filedesk/operations.py`: обнаружение файлов, построение плана без записи на диск, проверка имён, защищённое от перезаписи переименование, журнал и отмена. Модуль не зависит от Qt.
- `filedesk/settings.py`: SQLite-настройки. Каждая фоновая задача открывает собственное соединение с журналом в своём потоке.
- `tests`: ядро файловых операций, сохранение настроек, QML, полный проход через backend.
- `.github/workflows/checks.yml`: Linux/Windows проверки и Windows-сборка.

## Журнал

`batches`: время UTC и состояние пакета (running/done/errors/cancelled/interrupted).

`changes`: исходный и целевой пути, отпечаток (device/inode/size/mtime_ns/SHA-256), состояние и ошибка. Перед переименованием фиксируется pending, после — done. Ошибки и пропуски также сохраняются. Перед отменой фиксируется undoing, после — undone. После аварийного завершения pending/undoing становятся uncertain: эти операции не отменяются автоматически.

Отмена выбирает последний пакет с ещё не отменёнными done-записями. Файл должен совпасть с отпечатком, исходное имя должно быть свободно. Конфликт сохраняется в истории; операцию можно повторить после устранения конфликта.

## Границы гарантий

Пакет не атомарен. Проверка отмены включает чтение содержимого; крупный файл может требовать времени. SHA-256 считается в рабочем потоке порциями по 1 МиБ. Остановка не откатывает выполненное. Имена проверяются по правилам Windows даже при тестировании на Linux. Файловая операция запрещает перезапись существующего назначения. Сторонние изменения во время обработки не блокируются: есть временные промежутки между проверкой и операцией. Это утилита для файлов пользователя, а не защита от враждебного процесса в общей папке.

На этапе изображений результаты сохранять отдельно от оригиналов. В сценариях использовать тот же механизм очереди, отмены и журнала, расширив тип операции.

`filedesk/selftest.py`: интеграционная проверка интерфейса и файлов, запускаемая также внутри собранного Windows exe. `GlassPanel.qml` и `Glyph.qml`: оформление по референсу и векторные иконки.
