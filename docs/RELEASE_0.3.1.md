Скачайте FileDesk.exe и запустите его. Отдельная папка _internal, установленный Python и ручная распаковка библиотек не нужны. При запуске приложение само размещает библиотеки во временной папке, поэтому первое открытие может занимать несколько секунд.

Настройки интерфейса отделены от журнала операций: смена темы/меню больше не конкурирует за запись в базу с переименованием. По умолчанию используется программная отрисовка Qt Quick, добавлены filedesk.log и crash.log в системной папке данных приложения. Старый журнал и настройки сохраняются при обновлении.

Проверка собранного exe включает импорт, переименование, отмену, демоисторию и очередь из 400 файлов с переходами по интерфейсу во время обработки.

Это предварительная неподписанная сборка. Предупреждение SmartScreen может сохраняться. SHA256SUMS.txt позволяет проверить целостность скачанного файла, но не заменяет цифровую подпись. Точная причина ранее сообщённого аварийного закрытия не установлена без журнала с компьютера пользователя.
