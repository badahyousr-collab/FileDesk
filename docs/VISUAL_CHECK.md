# Проверка на Windows

Пока не выполнена на реальной Windows-системе. Использовать копии тестовых файлов.

1. Распаковать сборку, запустить FileDesk.exe без установленного Python.
2. Проверить перемещение, края окна, сворачивание, разворачивание и восстановление.
3. Проверить масштаб 100%, 125%, 150%, 200% и минимальный размер окна.
4. Открыть разделы, свернуть и раскрыть меню, переключить темы; перезапустить и проверить сохранение.
5. Добавить файлы через диалог и drag-and-drop, затем вложенную папку; повторные пути не должны дублироваться.
6. Задать `catalog_{n:03d}`, проверить таблицу, выполнить переименование и проверить папку в Проводнике.
7. Перезапустить и отменить переименование. Проверить восстановление имён и содержимого.
8. Проверить занятое имя, запрещённое имя, кириллицу, длинный путь, файл без прав и файл, открытый другой программой с запретом переименования.
9. После переименования изменить один файл и занять исходное имя другого. Отмена должна отказать для этих файлов без перезаписи; причины видны в истории.
10. Остановить большую очередь. Выполненные файлы остаются в истории; новые не обрабатываются. Проверить отзывчивость окна.
11. Проверить полосы прокрутки таблицы, панели параметров и истории, а также клавиатурную навигацию.

Системное размытие пока не реализовано. Linux/offscreen не подтверждает Windows DPI и реальные блокировки файлов.
